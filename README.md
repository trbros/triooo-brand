# triooo — marca, wallpapers e avatares

[Português](README.md) · [English](README.en.md) · [Español](README.es.md)

Arquivos oficiais da marca [triooo](https://triooo.com.br): logo, papéis de parede em 4K e avatares para redes sociais. Os wallpapers e os avatares de partículas usam a mesma animação do site.

**Baixar tudo:** [wallpapers 4K (ZIP)](https://github.com/trbros/triooo-brand/releases/latest/download/triooo-wallpapers-4k.zip) · [wallpapers de celular (ZIP)](https://github.com/trbros/triooo-brand/releases/latest/download/triooo-wallpapers-celular.zip) · [avatares (ZIP)](https://github.com/trbros/triooo-brand/releases/latest/download/triooo-avatares.zip) · [logo (ZIP)](https://github.com/trbros/triooo-brand/releases/latest/download/triooo-logo.zip)

## Gerar novas variações

A pasta [`gerador/`](gerador) tem o desenho (`render.html`), as listas de peças (`variants.json` e `avatars.json`) e o script de captura (`shoot.mjs`, com Playwright). Cada peça usa um sorteio fixo (`seed`), então sai sempre igual.

```sh
npm i -D playwright && npx playwright install chromium
node gerador/shoot.mjs "$PWD/gerador/render.html" gerador/variants.json saida/
node gerador/shoot.mjs "$PWD/gerador/render.html" gerador/variants-celular.json saida/celular/
```

Parâmetros: `loop {cx, cy, width}`, `count`, `fade` (rastro), `speedMul`, `spread`, `sizeMul`, `alpha`, `outline`, `glow`, `grid`, `vignette`, `colors`, `seed`, `timeMs` e `text.layout` (`hero`, `center`, `corner`, `type`, `logo`, `stack`, `mark`, `fulllogo`, `none`).

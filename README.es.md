# triooo — marca, fondos de pantalla y avatares

[Português](README.md) · [English](README.en.md) · [Español](README.es.md)

Archivos oficiales de la marca [triooo](https://triooo.com.br): logo, fondos de pantalla en 4K y avatares para redes sociales. Los fondos y los avatares de partículas usan la misma animación del sitio.

**Descargar todo:** [fondos 4K (ZIP)](https://github.com/trbros/triooo-brand/releases/latest/download/triooo-wallpapers-4k.zip) · [fondos para celular (ZIP)](https://github.com/trbros/triooo-brand/releases/latest/download/triooo-wallpapers-celular.zip) · [avatares (ZIP)](https://github.com/trbros/triooo-brand/releases/latest/download/triooo-avatares.zip) · [logo (ZIP)](https://github.com/trbros/triooo-brand/releases/latest/download/triooo-logo.zip)

## Generar nuevas variaciones

La carpeta [`gerador/`](gerador) tiene el diseño (`render.html`), las listas de piezas (`variants.json` y `avatars.json`) y el script de captura (`shoot.mjs`, con Playwright). Cada pieza usa una semilla fija (`seed`), así que siempre sale igual.

```sh
npm i -D playwright && npx playwright install chromium
node gerador/shoot.mjs "$PWD/gerador/render.html" gerador/variants.json salida/
node gerador/shoot.mjs "$PWD/gerador/render.html" gerador/variants-celular.json salida/celular/
```

Parámetros: `loop {cx, cy, width}`, `count`, `fade` (estela), `speedMul`, `spread`, `sizeMul`, `alpha`, `outline`, `glow`, `grid`, `vignette`, `colors`, `seed`, `timeMs` y `text.layout` (`hero`, `center`, `corner`, `type`, `logo`, `stack`, `mark`, `fulllogo`, `none`).
